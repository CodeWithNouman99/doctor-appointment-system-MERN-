# Prescripto: Doctor Appointment Booking System

A MERN stack web app to browse doctors by speciality and book appointments.

> 🚧 In development. Frontend home page is complete; backend is coming next.

## Tech Stack

- **Frontend:** React (Vite), Tailwind CSS, React Router, Context API
- **Backend:** Node.js, Express.js, MongoDB (in progress)

## Features

- [x] Responsive home page
- [x] Browse doctors by speciality
- [ ] Book and cancel appointments
- [ ] User authentication (JWT)
- [ ] Doctor and Admin panels

## Run Locally

```bash
git clone https://github.com/CodeWithNouman99/doctor-appointment-system-MERN-.git
cd doctor-appointment-system-MERN-/Frontend
npm install
npm run dev
```
